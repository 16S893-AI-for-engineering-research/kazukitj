Log protocol / 001

Document the process, not just the output.

I will use this page throughout 16.S893 to document meaningful interactions with AI agents. Each entry records the task, the tool, the agent’s contribution, and my own role in directing and evaluating the work.

The aim is not simply to list prompts. It is to reflect on when an agent was useful, where its output needed judgment or revision, and how the collaboration affected the result.

What I asked

I asked the coding agent to create a Dev-log page where I can record the ways I use AI agents during the course.

How the agent helped

The agent inspected the existing static site, reused its visual and semantic patterns, created this page, connected it to every page, and added responsive styles for the log entries.

My role + reflection

I defined the need for the page and remain responsible for checking the accuracy of each disclosure. Using the agent made it possible to integrate the feature consistently across the site rather than treating the log as a disconnected add-on.

Outcome A reusable format for documenting future AI-assisted work.

Building the course website.

What I asked

I used an AI coding agent to turn my introduction and preliminary project idea into a small course website.

How the agent helped

The agent developed the page structure, visual system, responsive layouts, and lightweight interactions in HTML, CSS, and JavaScript.

My role + reflection

I supplied the personal and research context that shaped the content and direction. The process showed how an agent can move quickly from source material to a coherent implementation, while still requiring me to verify that the result represents my work accurately.

Outcome A working foundation that can grow with the course.

Ongoing protocol

Three rules for future entries.

  1. Disclose. Name the tool and describe its actual contribution.
  2. Verify. Check generated claims, code, and artifacts before relying on them.
  3. Reflect. Record what changed because an agent was involved—and what still required human judgment.
