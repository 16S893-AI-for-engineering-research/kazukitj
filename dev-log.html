Entry 004 / Project communication

Turning the proposal into a three-minute story.

24 Sep
2026
Agent
Codex coding agent
Mode
Proposal synthesis, information design, implementation, and responsive verification
Artifact
Scrollable three-minute course-project presentation

What I was working on

I had completed a new one-page project proposal and needed the portfolio to reflect it. I wanted the project page to remain useful as a written explanation while also functioning as the visual structure for a three-minute lightning talk in class.

How the agent helped

I asked Codex to read the proposal, identify a concise spoken narrative, and redesign the existing page around it. The resulting five-part route moves from the CFD-analysis bottleneck to the AI-specific research question, the source-and-vorticity representation, the proposed Teams A-E virtual lab, and the questions the project should answer. Codex implemented the layout, diagrams, timed navigation, active scroll indicator, and responsive behavior.

My role + reflection

I authored the proposal, defined the three-minute presentation constraint, and checked that the distilled page retained the important scientific distinctions: representation is non-unique, extraction is a separate problem, and evaluation still requires physical judgment. I reviewed the desktop and phone previews before publishing. Converting prose into a sequence of audience-facing claims made the project's logic clearer without replacing the full technical proposal.

Outcome A project page that doubles as a concise public explanation and a timed visual route for the class lightning talk.

Entry 003 / Skill assignment

Developing a scientific-plotting skill.

21 Sep
2026
Agent
Pi coding agent · GPT-5.6 via MIT Parley
Mode
Standards synthesis, skill authoring, documentation, and structural verification
Artifact
Reusable scientific-plotting skill for this course portfolio

Why I created it

I wanted the agent to follow a consistent, auditable workflow whenever it helps turn scientific results into figures. Rather than restating plotting constraints in each request, I asked it to create a reusable course skill that makes the assumptions behind grouping, summarizing, transforming, and interpreting data explicit.

How the agent helped

The agent adapted my existing scientific plotting standard into step-by-step instructions and a verification checklist. The skill directs an agent to identify authoritative granular data, preserve provenance and complete configuration boundaries, show individual replicates with appropriate summaries, keep missing measurements missing, justify transformations, distinguish direct observations from unsupported interpretations, and save enough code and metadata to regenerate each figure. Dataset-specific filenames became general roles such as per-observation data, configuration metadata, and study records, while domain-specific accounting examples became checks for totals, nested components, and overlapping classifications. The core safeguards—no silent pooling, transparent replicate counts, bounded claims, and reproducible provenance—were retained.

My role + reflection

The skill can prompt careful procedure, but it cannot decide whether a grouping, transformation, summary, or interpretation is scientifically warranted. I still have to understand the experiment, choose and defend those decisions, inspect the underlying data and final figure, and determine whether the evaluation design supports a claim. The file and page structure were checked during this update, but the skill has not yet been exercised on a separate plotting task.

Outcome A reusable plotting workflow that carries my existing standards into future agent-assisted figure work while keeping scientific judgment and final verification with me.

Ongoing protocol
