LLMs for exploring flow analysis methods.

An early idea to use LLMs to automate the exploration of methods an AI agent could use to recognize flow mechanisms in CFD solutions.

01 / Question + context

How should an AI agent recognize flow mechanisms?

In my new AI-agent project, one of the most important tasks is determining which method is best for identifying flow mechanisms within CFD solutions.

The direction is not yet concrete and is still under discussion with my advisor, but it creates an opportunity to explore how LLMs might help investigate the question itself.

02 / Possible approaches

Explore beyond the human workflow.

One possibility is to emulate how a human expert analyzes a solution: make a hypothesis, analyze the data, and perhaps run more cases under different conditions to confirm or rule out that hypothesis.

An AI agent may also be capable of—and perhaps better suited to—methods that human experts do not typically use. We want to explore many possibilities, including:

  • Human-style analysis — Form hypotheses, inspect data, and run additional cases.
  • Adjoint calculations — Examine the sensitivity of flow variables.
  • Simplified comparisons — Match RANS CFD solutions with solutions using source and sink terms to view the case through another lens.

03 / Course project idea

Automate the exploration itself.

For 16.S893, I could use LLMs to automate the exploration of these analysis methods. The goal would be to investigate which approaches an AI agent could use rather than committing in advance to the process a human expert would follow.

This is ambitious, but it would be interesting to see what is possible.
